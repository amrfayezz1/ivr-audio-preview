# G Developments — IVR Audio Manager (Preview)

Static preview of the IVR audio scripts and recordings.

- `index.html` — the viewer UI
- `ivr_viewer.css`, `ivr_viewer.js` — styles and logic
- `ivr_data.js` — script/metadata (generated by `build_ivr_data.py`)
- `en_US/`, `ar_EG/` — generated `.wav` audio, organized by project

Deployed as a static site on Vercel. No build step required.
